# Т7.3 — біржа творчих замовлень

Marketplace: публічні підтверджені брифи, модерація MODERATION → OPEN,
фільтри/пагінація, detail, власні замовлення/заявки. Лише APPROVED фахівець
подає заявку з портфоліо, терміном і умовами; власник порівнює й явно
обирає одну. Версія замовлення захищає від одночасних рішень, історія
переходів зберігається. Відхилені/непублічні брифи не відкриваються гостям.
Новий публічний бриф не змінює вже OPEN/обране замовлення; для нового
завдання — новий CreativeProject. Бюджет фільтрується як текст умов,
оскільки §2.3 зберігає умови/договірний бюджет, а не нормалізовану валюту.

Studio: owner-only explicit sync з bridge зі звіркою Firebase UID автора
та фахівця, orderId/externalId. Той самий CreativeProject отримує вибір
і статус SPECIALIST_SELECTED. Немає автоматичних grants, ролей чи
запрошень; якщо фахівець ще не входив у Studio, показати очікування входу.

IN_PROGRESS/REVIEW/COMPLETED переходи — Т7.4; enum існує, але довільних
кнопок/обіцянок цих станів немає. CANCELLED/ARCHIVED — явні дії автора.
Немає escrow/гарантій/платежів. Точна верстка Stitch 9 — Т8.3; вихідного
макета у checkout немає, UI використовує поточні компоненти Marketplace.

Перевірки: міграція та Prisma, повний API e2e, конкуренція selection,
private/owner/approved/outsider guards, повтор bridge без перезапису
OPEN, реальний Studio sync без grants, browser UA/EN+390px,
npm test/types/build, журнал і production-сценарій.
