# Шаблон Eisvogel

`eisvogel.latex` — шаблон pandoc для LaTeX з репозиторію
[Wandmalfarbe/pandoc-latex-template](https://github.com/Wandmalfarbe/pandoc-latex-template),
**версія 3.5.0**, узятий із релізного архіву `Eisvogel.zip`.

Ліцензія — BSD 3-Clause, повний текст у `EISVOGEL-LICENSE` (Pascal Wagler,
John MacFarlane). Файл лишається незміненим; усі наші налаштування
передаються pandoc через `-V`, а не правками в шаблоні — інакше оновлення
до наступної версії перетворилось би на ручне звіряння двох тисяч рядків.

**Чому файл лежить у репозиторії, а не качається при збірці.** У самому Git
цього файлу немає: він збирається під час релізу з кількох частин (див.
README шаблону). Тобто «взяти свіжий при деплої» означало б залежність
кожної збірки образу від доступності GitHub і від того, що в новому релізі
нічого не поїхало. Верстка книги, яку вже продають, від цього залежати не
може.
