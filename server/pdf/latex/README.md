# Шаблон Eisvogel

`eisvogel.latex` — шаблон pandoc для LaTeX з репозиторію
[Wandmalfarbe/pandoc-latex-template](https://github.com/Wandmalfarbe/pandoc-latex-template),
**версія 3.2.0**, узятий із релізного архіву `Eisvogel.zip`.

Ліцензія — BSD 3-Clause, повний текст у `EISVOGEL-LICENSE` (Pascal Wagler,
John MacFarlane). Файл лишається незміненим; усі наші налаштування
передаються pandoc через `-V`, а не правками в шаблоні — інакше оновлення
до наступної версії перетворилось би на ручне звіряння двох тисяч рядків.

## Чому 3.2.0, а не найновіша

Спершу було взято 3.5.0 — і воно не зібралося. Причина конкретна:
**Eisvogel 3.5.0 підключає пакет `sourcesans`, а це назва з TeX Live 2024.**
У TeX Live 2023, який їде в Debian stable, той самий пакет називається
`sourcesanspro`, і збірка падає з `File 'sourcesans.sty' not found`.

Тобто вибір стояв не «свіжіше чи старіше», а «шаблон під TeX, який у нас є,
чи ще пʼять гігабайтів заради ставлення TeX Live з upstream-інсталятора».
Узято перше. 3.2.0 — остання версія, що підключає `sourcesanspro`.

Перевірено збіркою: pandoc 3.1.3 + XeTeX (TeX Live 2023) + DejaVu дають
книгу з титульною сторінкою, змістом і правильною кирилицею.

**Коли база образу перейде на TeX Live 2024+** — можна й потрібно оновити
шаблон до найновішого. Ознака, що час настав: `kpsewhich sourcesans.sty`
щось знаходить.

## Чому файл лежить у репозиторії, а не качається при збірці

У самому Git цього файлу немає: він збирається під час релізу з кількох
частин (див. README шаблону). Тобто «взяти свіжий при деплої» означало б
залежність кожної збірки образу від доступності GitHub і від того, що в
новому релізі нічого не поїхало. Верстка книги, яку вже продають, від
цього залежати не може.

## Шрифти передаються ВСІ ТРИ, і це не перестраховка

`mainfont`, `sansfont`, `monofont` — обовʼязково разом. Eisvogel набирає
заголовки шрифтом без засічок, і якщо задати лише `mainfont`, XeLaTeX
візьме для них Latin Modern, у якому кирилиці немає: заголовки виходять
порожніми, а в лозі — сотні рядків `Missing character`. Перевірено
експериментально, а не з документації.
