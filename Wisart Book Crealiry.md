## 1. Загальний опис і мета системи
**«Цифрова майстерня письменника»** — це програмний комплекс для інтелектуального проєктування, сценарного моделювання, структурної генерації та безпосереднього написання текстів різних форматів:
1. **Художня література (Книги)** — із застосуванням мономіфу, ведичних батьківських статусів, буддійських скандх та 36 драматичних патернів Жоржа Польті.
2. **Курсові та наукові роботи** — згідно з академічними стандартами структурування наукового апарату.
3. **Навчальні курси** — із проєктуванням модулів на базі таксономії Блума та моделі ADDIE.
4. **Технічні інструкції (Manuals)** — алгоритми монтажу, експлуатації та регламентів безпеки (ANSI/ISO).

## 3. Функціональна специфікація Майстра (Wizard Engine)

### 3.1. Крок 0: Маршрутизатор режимів (`projectType`)
Обов'язковий вибір типу створюваного проєкту, що визначає склад наступних кроків майстра:
* `book` — Художня література.
* `coursework` — Курсова / Наукова робота.
* `training_course` — Навчальний курс / Освітня програма.
* `manual` — Інструкція з експлуатації / збирання.

---

### 3.2. Специфікація гілки: Художня книга (`book`)

#### Крок 1: Метадані книги
* Поле `title`: Рядок введення (обов'язкове, до 150 символів).
* Поле `genres`: Комбінований Multi-Select (`Creatable`) із підтримкою змішування стандартних жанрів або введення власного формулювання (наприклад, *«Філософський кіберпанк із нуарними елементами»*).

#### Крок 2: Сценарні та філософські моделі (`framework`)
* `hero_journey` — Подорож героя (12 стадій Джозефа Кемпбелла).
* `psychotypes` — Розвиток сюжету через зіткнення внутрішніх суперечностей і характерів.
* `vedic_archetypes` — Структура через еволюцію трьох гун (Тамас $\to$ Раджас $\to$ Саттва) та дхармічні вузли.
* `buddhist_skandhas` — Розгортання через трансформацію 5 скандх: Форма (*Рупа*), Відчуття (*Ведана*), Сприйняття (*Санджня*), Формуючі фактори (*Самскара*), Свідомість (*Віджняна*).

#### Крок 3: Патерни поведінки та динаміки
* `[x] natureConnection` (Boolean): Генерація взаємозв'язку внутрішнього стану героїв із природними явищами, стихіями та сезонами.
* `[x] archetypes36` (Boolean): Підключення бібліотеки 36 сюжетно-поведінкових патернів Жоржа Польті.

#### Крок 4: Матриця персонажів
* Створення базового пулу із 6 слотів персонажів із можливістю динамічного додавання (`+ Додати героя`) та видалення.
* **Поля персонажа:**
  * `firstName`, `lastName` (Рядки).
  * `psychotype` (Рядок / Вибір).
  * **Батьківські ролі Ведичної традиції:**
    * *7 матерів (Сапта-мата):* Атма-мата (рідна мати), Гуру-патні (дружина вчителя), Раджа-патні (дружина правителя), Брахмані (духовна мати/дружина священника), Дхену/Ґау-мата (корова-годувальниця), Дхатрі (няня/годувальниця), Прітхві/Бхумі (земля/батьківщина).
    * *5 батьків (Панча-піта):* Джаніта (біологічний батько), Упаніта (ініціатор духовного життя), Від'я-дата (вчитель/ачар'я), Анна-дата (годувальник/меценат), Бхая-трата (захисник від небезпеки та страху).
  * **36 патернів Польті:** Випадаючий список із закріпленням драматичного амплуа (Месник, Благаючий, Бунтівник, Честолюбець, Невинно засуджений тощо).

#### Крок 5: Інтегрований конструктор «Шлях героя» (13 кроків)
Автономна форма для детального пропрацювання ключових героїв:
1. Старий герой (статус-кво).
2. Внутрішня проблема (хибна установка / The Lie).
3. Поклик (тригер змін).
4. Страх / Відмова (сумніви).
5. Наставник (джерело знань/інструменту).
6. Поріг (спалення мостів).
7. Випробування (руйнування старого світогляду).
8. Найглибша криза (символічна смерть старого "Я").
9. Трансформація (усвідомлення істини / The Truth).
10. Дар (здобуття сили/нагороди).
11. Повернення (рух назад у зміненому стані).
12. Новий герой (оновлені цінності).
13. Дар для світу (зовнішній результат подорожі).

* **AI Transformation Auditor:** Алгоритм аналізує зіставлення кроків (1 vs 12, 2 vs 8, 10 vs 13), розраховує індекс трансформації (`transformationScore`: 0–100) та повертає текстові рекомендації для ліквідації сценарних дірок.

#### Крок 6: Синопсис із розумним автодоповненням
* Текстове поле на 500–700 слів із валідатором довжини.
* **Mention / Quick Insert:** Введення літери або `@` викликає контекстне меню автодоповнення іменами створених на Кроці 4 персонажів із посимвольною підсвіткою збігів (Highlighting).

#### Крок 7–8: AI Генерація та перегляд структури
* Фоновий запит до LLM через асинхронну чергу.
* Повернення плану: Частини $\to$ Глави $\to$ Задіяні персонажі $\to$ Синопсис сцени $\to$ Поворотний пункт $\to$ Зв'язок із природою/стихією.

## 4. Реєстр патернів Польті та Матриця конфліктів

### 4.1. Довідник 36 драматичних ситуацій (Жорж Польті)

2. **Визволення** (Рятівник, В'язень, Гнобитель).
3. **Помста за злочин** (Месник, Злочинець).
4. **Помста між близькими** (Кровний месник, Родич-убивця).
5. **Переслідування** (Втікач, Мисливець).
6. **Спустошення / Катастрофа** (Переможений володар, Загарбник).
7. **Падіння у злидні** (Знедолений, Безжальний господар).
8. **Бунт проти влади** (Бунтівник, Тиран).
9. **Зухвалість / Смілива спроба** (Сміливець, Охоронець мети).
10. **Викрадення / Полон** (Викрадач, Полонений, Шукач).
11. **Загадка / Таємниця** (Шукач істини, Хранитель таємниці).
12. **Здобуття силою** (Загарбник, Оборонець).
13. **Ненависть між родичами** (Ворогуючі родичі, Спірне майно).

20. **Самопожертва заради ідеалу** (Герой-мученик, Ідеал/Справа).
21. **Самопожертва заради близьких** (Жертовний захисник, Врятований).
22. **Жертва пристрасті** (Засліплений коханець, Фатальний об'єкт).
23. **Обов'язок жертвувати близькими** (Суддя/Виконавець, Приречений родич).
24. **Суперництво нерівних** (Слабкий претендент, Могутній суперник).
25. **Перелюб і зрада довіри** (Обманщик, Ошуканий партнер).

27. **Безчестя коханої особи** (Захисник честі, Зганьблена особа, Нападник).

30. **Честолюбство / Жага влади** (Честолюбець, Суперник).
31. **Богоборництво / Виклик долі** (Бунтівник проти вищого закону, Фатум).

35. **Віднайдення втраченого** (Шукач, Знайдений родич/спадкоємець).
36. **Втрата близьких** (Той, хто оплакує, Загиблий).

### 4.2. Алгоритм взаємозв'язку (Clash Engine)
* **Match Making:** Автоматичне визначення пар із комплементарними амплуа (наприклад, №33 *Невинно засуджений* та №32 *Наклепник*).
* **Graph Generator:** Формування топології зв'язків для візуалізації в компоненті React Flow:
  * Червоні ребра: Антагоністичний конфлікт інтересів.
  * Зелені ребра: Союзництво / Синівський або батьківський борг.
  * Жовті пунктирні ребра: Прихована зрада / Фатальна таємниця.

## 5. Специфікація робочого простору (Workspace Editor)

При переході з Кроку 8 за кнопкою **«Додати план в книгу та розпочати писати»**:
1. Ініціалізується новий документ проєкту.
2. Автоматично рендериться сторінка «Зміст» (Table of Contents) із гіперпосиланнями на розділи.
3. Кожна згенерована глава/розділ автоматично виноситься на **нову фізичну сторінку** через вузол `PageBreak` Tiptap-редактора.
4. Вмикається трипанельний інтерфейс:
   * **Лівий сайдбар:** Дерево розділів, картки персонажів із ведичними ролями, поточні статуси арок «Шляху героя», міні-карта графу конфліктів.
   * **Центральна робоча зона:** Сторінковий редактор (A4 layout) із нумерацією, колонтитулами та відступами.
   * **Правий AI-копілот:** Виклик контекстних дій («Розписати сцену за патерном», «Поглибити конфлікт між персонажами Х та Y», «Перевірити відповідність стихії глави»).

## 6. Модель бази даних (Prisma Schema)

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

enum ProjectType {
  BOOK
  COURSEWORK
  TRAINING_COURSE
  MANUAL
}

enum FrameworkType {
  HERO_JOURNEY
  PSYCHOTYPES
  VEDIC_ARCHETYPES
  BUDDHIST_SKANDHAS
}

enum VedicRoleType {
  NONE
  // Сапта-мата (7 матерів)
  ATMA_MATA
  GURU_PATNI
  RADJA_PATNI
  BRAHMANI
  DHENU_GAU
  DHATRI
  PRITHVI_BHUMI
  // Панча-піта (5 батьків)
  JANITA
  UPANITA
  VIDYA_DATA
  ANNA_DATA
  BHAYA_TRATA
}

model Project {
  id               String                  @id @default(uuid())
  title            String                  @db.VarChar(255)
  projectType      ProjectType
  genres           String[]
  framework        FrameworkType?
  natureConnection Boolean                 @default(false)
  archetypes36     Boolean                 @default(false)
  synopsis         String?                 @db.Text
  specificConfig   Json?                   // Специфічні налаштування для coursework/course/manual
  
  characters       Character[]
  relationships    CharacterRelationship[]
  sections         Section[]

  createdAt        DateTime                @default(now())
  updatedAt        DateTime                @updatedAt

  @@index([projectType])
}

model Character {
  id              String         @id @default(uuid())
  projectId       String
  project         Project        @relation(fields: [projectId], references: [id], onDelete: Cascade)
  
  firstName       String         @db.VarChar(100)
  lastName        String         @db.VarChar(100)
  psychotype      String?        @db.VarChar(100)
  vedicRole       VedicRoleType  @default(NONE)
  poltiPatternId  Int?
  poltiRoleName   String?        @db.VarChar(100)
  
  heroJourneyArc  Json?          // Об'єкт із 13 кроків арки героя
  arcScore        Int?           // Оцінка валідатора (0-100)

  sourceRelations CharacterRelationship[] @relation("SourceCharacter")
  targetRelations CharacterRelationship[] @relation("TargetCharacter")

  createdAt       DateTime       @default(now())
  updatedAt       DateTime       @updatedAt

  @@index([projectId])
}

model CharacterRelationship {
  id              String      @id @default(uuid())
  projectId       String
  project         Project     @relation(fields: [projectId], references: [id], onDelete: Cascade)
  
  sourceId        String
  sourceChar      Character   @relation("SourceCharacter", fields: [sourceId], references: [id], onDelete: Cascade)
  
  targetId        String
  targetChar      Character   @relation("TargetCharacter", fields: [targetId], references: [id], onDelete: Cascade)
  
  conflictType    String      @db.VarChar(50) // direct_antagonism, alliance, latent_threat
  description     String      @db.Text
  patterns        Int[]

  createdAt       DateTime    @default(now())

  @@index([projectId])
}

model Section {
  id               String      @id @default(uuid())
  projectId        String
  project          Project     @relation(fields: [projectId], references: [id], onDelete: Cascade)
  
  orderIndex       Int
  partNumber       Int         @default(1)
  partTitle        String?     @db.VarChar(255)
  title            String      @db.VarChar(255)
  stageTag         String?     @db.VarChar(100)
  environmentalCtx String?     @db.Text
  summary          String?     @db.Text
  content          String      @default("") @db.Text

  createdAt        DateTime    @default(now())
  updatedAt        DateTime    @updatedAt

  @@index([projectId, orderIndex])
}

# СИСТЕМНИЙ ПРОМПТ: Генератор структури книги (Book Structure Orchestrator)

### РОЛЬ
Ти — провідний сценарний аналітик, наративний архітектор та літературний редактор. Твоє завдання — згенерувати детальний, драматично вивірений план книги на основі переданих параметрів у форматі JSON.

### ПРАВИЛА ОБРОБКИ ПАРАМЕТРІВ:
1. **framework:**
