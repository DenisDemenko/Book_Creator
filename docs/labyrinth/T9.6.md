# Т9.6 — цифровий читач книги-лабіринта

Реалізація 12.10.2026, Core v38. Використано чинний PostgreSQL pool і runtime Т9.3–Т9.5. [Production-приймання](../acceptance/T9.6.md).

## Версія та права

Власник або адміністратор явно відкриває збережену карту й героїв для сольного читання. Кожен герой перевіряється на прохідність. Знімок фіксує поточну ревізію книги, описи вузлів та тексти прив'язаних сцен. Він незмінний на рівні SQL; новий реліз застосовується до нових стартів, старі проходження зберігають свою версію.

У знімок входять paragraph/heading/blockquote; draft/image/table не включаються. Розмір — до8МБ. Текст відображається як текст, без виконання HTML.

Читач має бути авторизованим учасником із переглядом всієї книги. Доступ лише до сцени не надає весь лабіринт. Нові grants не створюються. Кожен запит перевіряє чинні права; перед записом дії права перевіряються повторно. Відкликання релізу закриває старі сесії; повторне відкриття не воскресає відкликані проходження.

## Серверна проєкція

Кожне проходження належить одному користувачеві й одному герою. Чужі читацькі GET/actions/restore повертають404, навіть іншому адміністратору. Авторський повний preview має окрему межу власник/адміністратор. Його список не містить читацьких run; author structural/runtime/director/restore відхиляють reader run із403, щоб не змінювати стан поза читацьким потоком.

DTO формується явним переліком полів: поточна сцена, власні ресурси/предмети/знання, місцеві переходи та взаємодії, запущені локальні попередження, відкриті вузли й метадані власних checkpoints. Повної definition/state, інших героїв, planned events, seed, trace або proof у ньому немає.

Туман відкриває відвідані вузли та видимі з них сусідні переходи. Текст наступної сцени віддається після прибуття. Назви невідомих кінців мостів редагуються в «невідкрите місце».

Чинне право перегляду рукопису в інших API Studio не звужується. Туман читацького API захищає сценарну структуру та стан, але не замінює окрему роль лише для проходження без доступу до рукопису; таке розширення прав залишається наступним.

## Час, дії й checkpoints

ReaderAction: move(edgeId), interact(objectId,to), wait. Героя визначає сервер. Читач не запускає події вручну і не змінює seed/правила. Runtime перевіряє поточні дозволені дії та доказ безпечного продовження. Помилки не повертають прихований маршрут proof.

Директор працює за локальними затвердженими правилами після дії, без платних Jev/LLM. GET/reload/читання/пауза не рухають час. Збережений стан включає активні небезпеки. Досягнення виходу завершує ігрові дії.

CAS ревізії запобігає подвійному ходу. Старт/дія/відновлення мають ключ повтору. UI після втрати відповіді повторює той самий запит із тим самим ключем. Відновлення створює новий run зі станом, часом, ресурсами, знаннями, туманом і напрямком checkpoint; оригінал незмінний. UI показує останні100 checkpoints.

## Вхід і API

Меню Studio → **Читач лабіринта** доступне авторизованим ролям, включно з читачем. Авторський Конструктор структури залишається закритим ролі читача. Прямий маршрут: /studio/projects/:projectId/labyrinth-reader.

Додаткова вкладка читача є у конструкторі для автора. Bookmark використовує labyrinth=reader і readerRun; приватні тексти/state не зберігаються в Web Storage. SVG-карта має два рівні, маркер, назву й текстову альтернативу. Кнопки й відновлення доступні клавіатурою; після дії фокус переходить на сцену. Є розмір тексту та покроковий режим без таймера.

Префікс API: /api/core/projects/:projectId/labyrinth; усі відповіді no-store.

| Метод/шлях | Призначення |
|---|---|
| GET /maps/:mapId/reader-publication | Автор: стан відкритої версії |
| POST /maps/:mapId/reader-publication | Автор: expectedRevision, mapRevision, heroIds |
| POST /maps/:mapId/reader-withdraw | Автор: відкликання з CAS |
| GET /reader/library | Доступні версії та тільки свої маршрути |
| POST /reader/maps/:mapId/start | publicationRevision, heroId, key |
| GET /reader/sessions/:runId | Фільтрована поточна сцена |
| POST /reader/sessions/:runId/actions | expectedRevision, action, key |
| POST /reader/sessions/:runId/restore | expectedRevision, sourceRevision, key |

## Межі

Сольний режим; група/різні знання/голосування/журнал внесків — Т9.7. Рукопис, співавторство й видання — Т9.8–Т9.10. Відкриття версії для учасників не є продажем або публічним виданням.

Production/Firebase, Railway restart, Safari/VoiceOver/NVDA потребують ручного приймання. Платний AI не перевірявся і не потрібний цьому читачеві.
