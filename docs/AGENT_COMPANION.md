# Локальний помічник Студії

Шлях: Адмінка → Історія комітів → Прийом і передача → Підключення комп’ютера та Git.

## Архітектура
Браузер адміністратора ставить команду в чергу Express/SQLite.
Node.js-помічник на Windows сам опитує сервер через HTTPS кожні 2,5 секунди,
виконує Git через execFile без shell і надсилає результат.
Вхідних портів, тунелю, LLM і нового платного сервісу немає.

## Встановлення
Потрібна ця версія коду і на сервері Студії, і локально. Спочатку перегляньте
та злийте гілку реалізації; сам PR не встановлює функцію.
Потрібні Node.js 22+, Git for Windows і вже налаштований доступ Git до GitHub.
У вкладці створіть токен, потім з PowerShell у корені Book_Creator:
```powershell
.\scripts\start-agent-companion.ps1 -StudioUrl 'https://app.fusionlab.in.ua/studio' -RepositoryPath 'D:\Rama\Book_Creality'
```
Вставте токен у прихований запит. Залиште процес відкритим.
Для маркетплейсу використовуйте той самий скрипт із його RepositoryPath.
Токен діє 24 години; після завершення строку створіть нове підключення.
Токен зберігається тільки в пам’яті помічника; сервер зберігає його SHA-256.
Якщо політика Windows забороняє запуск скриптів, застосуйте дозволений у вашому
середовищі спосіб запуску; скрипт не змінює системну ExecutionPolicy.

## Команди
- status та staged-diff: перегляд.
- stage-file: один вибраний файл; без директорій, symlink, виходу за корінь.
- commit: поточний індекс, явний опис і перевірка очікуваних HEAD/гілки/індексу.
- push: тільки Book_Creator або Fusion-Lab-Marketplaes; одна відома push-адреса,
  явні SHA та поточна гілка; без force. Після push — ls-remote і порівняння SHA.
- receive: лише чисте дерево, fetch і merge --ff-only; конфлікти не вирішуються.

Підключення керує тільки папкою, вказаною при локальному запуску. Веб-сторінка
не може змінити цю папку чи передати довільну PowerShell-команду.
На час запису враховується tmp/session.lock. Один помічник на робочу копію:
.git/agent-companion.lock. Якщо процес аварійно завершився, спочатку перевірте,
що PID із цього файла вже не працює, і лише потім приберіть застарілий lock.

## Переривання та результати
Після втрати HTTP-відповіді помічник повторює надсилання результату, не команду.
Неприйнята команда спливає через 2 хвилини; результат запущеної стає невідомим
через 3 хвилини без підтвердження. Перед наступним записом потрібен status.
Відкликання токена скасовує ще не запущені команди; вже запущена може завершитися.
Ctrl+C припиняє нові опитування після поточної операції.
Операції Git не синхронізують SQLite. Використовуйте одну серверну Студію для
журналу і звичайне резервування її DATA_DIR/DATABASE_PATH.

## Перевірки перед використанням
```text
npm run lint
npm run build
npx tsx scripts/test-agentHandoff.mts
node --test scripts/test-agentCompanion.mjs
npm run journal:check
```
Ручне приймання: Windows + PowerShell, вхід адміністратора, pairing, статус,
вибраний файл, перегляд diff, commit, push на тестову гілку, receive.
Перевірити втрату мережі, повторну доставку результату, revoke, expiry,
дві паралельні сесії та заборону FusionLabPush. Деплой/живий запуск не
підтверджуються самим існуванням цих файлів.
