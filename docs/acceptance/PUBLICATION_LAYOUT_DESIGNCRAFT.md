# «Верстка для публікації» + шаблони + локальний DesignCraft — приймання

Запис журналу: #480 (25.10.2026). Що змінено, коротко:

- Сторінку «Верстка PDF / WYSIWYG-верстка перед публікацією» перейменовано на **«Верстка для
  публікації»**. Порядок блоків: шаблон → рушій і точний PDF → графічний редактор DesignCraft →
  ручна верстка рамок і обтікання (колишня канва без змін).
- **Шаблони «Верстка & Поля» на сторінці публікації.** Ті самі поля книги (формат, шаблон) через
  спільні `applyPageFormatPreset` / `applyBookDesignTheme`.
- **Дублікати назв прибрано.** Колишні «Класичний / Редакційний (Editorial)» з «Верстка & Поля»
  збігалися з темою Classic і варіантом Editorial каталогу DesignCraft. За рішенням власника
  згенеровано два нові шаблони: **Studio Classic** і **Studio Editorial** (`studio-classic`,
  `studio-editorial`). Тест `test:template-catalog` не пропустить нових дублікатів.
- **Знайдена й виправлена помилка:** обраний шаблон не передавався в точний PDF DesignCraft, EPUB/HTML і
  перегляд адміна — сервер верстав без теми. Тепер тема береться з книги (`designThemeFromBook`).
- **EPUB/HTML письменнику:** `/api/pdf/companion` (адмінський маршрут лишився адмінським).
- **Код підключення** замість копіювання токена: 8 символів, 5 хв, один раз, ліміт перебору.
- **Кнопка «Відкрити графічний редактор DesignCraft»** → посилання `designcraft-studio://` →
  `scripts/start-designcraft-studio.ps1`. Хмарна Студія — локальний сервер не запускається.
- **Конвеєр чернетки:** сервер верстає `.designcraft` тим самим V3, що й точний PDF → вікно
  DesignCraft → скрипт повертає документ і PDF у книгу (`designcraft`, `designcraft-pdf`).
  «Застаріло» — за вмістом (текст/макет/шаблон), а не за номером ревізії.

Що НЕ змінюється: серверний рушій Студії (Nova) тем не має; Studio Classic/Editorial впливають на
браузерний «Експорт видання» і DesignCraft. Текст із DesignCraft у Студію не повертається.

## Ручне приймання на Windows (власник)

1. `.\scripts\install-designcraft-link.cmd` — «Посилання designcraft-studio:// встановлено».
2. Локальна Студія → «Верстка для публікації»: шаблони показані, «Зараз: …» відповідає книзі.
3. Обрати Studio Editorial → «Точний PDF», рушій DesignCraft → «Створити точний PDF»: заголовки глав
   великі, ліворуч. Обрати Sci-Fi → заголовки гротеском.
4. «Отримати код підключення» → код XXXX-XXXX і таймер.
5. «Відкрити графічний редактор DesignCraft» → браузер питає дозвіл → вікно PowerShell:
   «Запуск із Студії: http://localhost:3000, книга …»; Студія НЕ перезапускається.
6. Ввести код → «Код прийнято», «Ви ввійшли як …».
7. Вікно DesignCraft відкривається; «Підготувати чернетку… (Y/n)» → Enter → файл у `designcraft-work`.
8. Claude Code відкриває чернетку у НОВІЙ вкладці вікна; інші вкладки не чіпає.
9. Після виходу з Claude Code: «Повернути ці файли в Студію? (Y/n)» → «Повернуто в Студію».
10. У Студії в блоці «Чернетка й результат DesignCraft» — «актуально»; змінити текст і зберегти → «застаріло».
11. Хмарна Студія (www.fusionlab.in.ua/studio, після деплою): кнопка → скрипт пише хмарну адресу і
    НЕ запускає локальний сервер; код береться в хмарній Студії.

Не перевірено тут: справжнє вікно DesignCraft на Windows (у хмарі немає GUI) і Rewrite маркетплейсу
для PUT великих файлів (> кількох МБ) на продакшені.
