# YOUTUBE-TRANSCRIPT-1 — імпорт розшифровки YouTube

Реалізовано 11.10.2026. Екран: Studio → База знань → YouTube · Розшифровка.

Книга має бути збережена на сервері. Операція доступна власнику або учаснику з повним прямим правом редагування книги. Частковий редактор, читач, сторонній і гість не отримують проєктне джерело. Співавтор, який працює через review/proposals, не обходить цей режим прямим імпортом.

Автоматичний імпорт читає лише доступні публічні caption tracks YouTube: мови, авторські/автоматичні субтитри, сегменти з таймкодами. Не використовує OCR/аудіорозпізнавання або ШІ. Якщо YouTube блокує запит, вимагає вхід чи не надає субтитрів, доступний ручний SRT/VTT/TXT. Доступність цього способу залежить від відповіді YouTube; обхід його обмежень не реалізовано.

Джерело додається через чинний onUpdateBook/storage flow Бази знань: локальне автозбереження та серверне дзеркало з перевіркою ревізії. Це не окреме підтвердження успішної серверної синхронізації: перевірте статус/серверну копію перед очищенням браузера. Новий імпорт не змінює глави; виділіть уривок у джерелі та скористайтеся чинною дією «Зберегти текст в книгу». Таймкоди належать оригіналу, редагований текст позначено окремо. Посилання на відео лишається в метаданих джерела та журналі вставлення.

## Виконані локальні перевірки

- 20/0 parser/API (оновлення #420): JSON3/XML legacy/srv3/VTT, порожні відповіді та один fallback, SRT/VTT, Unicode, таймкоди, дублі перекриттів, реальні повтори, розмір, SSRF, авторські/автоматичні tracks, відсутні captions/мова, guest/reader/stranger/disabled, редактор/власник, відкликання під час запиту.
- Chromium компонентний прогін з контрольованим API 5/0: preview, consent, cancel, confirmed save, відсутність JS помилок. Це не production або платний AI-прогін.
- Повний `npm test`, типізація та production build успішні (exit0).
- Прямий YouTube-запит у хмарі заблоковано мережевим проксі: CONNECT 403. Реальне отримання субтитрів не підтверджено.

## Ручне приймання після деплою — НЕ ВИКОНАНО

1. Під власником збережіть тестову книгу на сервері. У Базі знань введіть URL публічного відео з авторськими українськими субтитрами. Перевірте назву/мову/тип і звірте початок, середину та кінець із відео; переходи за таймкодами мають бути правильні.
2. Повторіть з автоматичними субтитрами й кількома мовами. Оберіть другу доріжку; текст і походження повинні змінитися. Перекриті однакові сегменти об’єднані, повтор після паузи збережений.
3. Без субтитрів, приватне/видалене/обмежене відео: зрозуміла помилка без вигаданого тексту. Завантажте SRT/VTT або вставте текст; OCR/ШІ не викликаються.
4. Файл із CRLF, українськими символами, тегами, NOTE та cue ID читається; неправильний час/порядок, файл понад 2 МБ відхиляються без зміни книги.
5. Скасуйте preview: джерела й глави незмінні. Відредагуйте текст/залиште уривок, підтвердьте права й збереження. Додано одне джерело з URL/мовою/походженням/датою/оригінальними таймкодами. Повторний імпорт того самого videoId/мови відхиляється з поясненням.
6. Виділіть уривок у джерелі, виберіть главу або тег і підтвердьте вставлення: змінюється тільки ціль. Перезавантажте браузер; перевірте серверне дзеркало й відновлення на другому пристрої. Конфлікт ревізії не повинен мовчки перезаписувати чужу книгу.
7. Окремо власник, повний редактор, scoped редактор, читач і сторонній. Перевірте прямі API запити; відкличте доступ під час отримання: пізня відповідь/наступне підтвердження відхиляються.
8. Некоректний URL, сторонній домен, credentials/порт, великий файл, недоступний YouTube, timeout: контрольовані помилки, без часткового збереження; можна повторити. Регресія чинного OCR та імпорту рукопису окремо.

Записуйте для кожного пункту: URL/версію застосунку, роль, кроки, очікуваний і фактичний результат, PASS/FAIL, докази. Реальні секрети в звіт не додавайте.
