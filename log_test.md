## #1 — Початок нумерації сторінок має задаватися явно → ✅ Виконано

**Постановка:** Початок нумерації сторінок повинен вказуватися користувачем явно, наприклад:
- після змісту, з першої глави;
- з титульної сторінки;
- або просто вибором номера сторінки.

**Реалізація:**
- У вкладці «Верстка PDF» (`PdfEditorView.tsx`) додано блок **«Початок нумерації»** із трьома режимами:
  - **«З титульної сторінки»** — титул = сторінка 1 (нумерація природна);
  - **«Після змісту»** — перша глава = сторінка 1 (з підказкою «З першої глави = сторінка 1»);
  - **«Вказати номер»** — поле для явного початкового числа (перша глава = вказане число).
- Налаштування зберігаються в `layoutConfig.typography.pageNumberStart { mode, startNumber }` (`types.ts`).
- Прев'ю на канві перераховує номер глави залежно від обраного початку (з титулу → як у змісті; після змісту → перша глава = 1; власний номер → перша глава = N).
- Експорт (`helpers.ts`): для режимів «after-toc»/«custom» у першу главу додається `counter-reset: page N` (classic та editorial), щоб нумерація в готовому PDF починалась із потрібного числа.

**Перевірка:** смоук-тест експорту (after-toc → `counter-reset: page 0`; custom 5 → `counter-reset: page 4`; title → без скидання; editorial теж). Перевірка в браузері: перемикання режимів змінює прев'ю (6 → 1 → 10), поле «Початковий номер» з'являється в режимі «Вказати номер».

## #2 — Шість позицій номера сторінки → ✅ Виконано

**Постановка:** Позиція номера сторінки має бути 6 штук:
- Внизу, по центру; Внизу, зліва; Внизу, справа;
- Вгорі, зліва; Вгорі, справа; Вгорі, по центру.

**Реалізація:**
- Тип `pageNumberPosition` розширено з 3 до 6 значень (`'bottom-center' | 'bottom-left' | 'bottom-right' | 'top-left' | 'top-right' | 'top-center'`) — `types.ts`.
- Панель «Позиція номера» у `PdfEditorView.tsx` тепер показує 6 кнопок у сітці 3×2.
- Канва: номер рендериться у вибраній позиції (по центру зі зсувом `translateX(-50%)`, або в кутах за відступами).
- Експорт (`helpers.ts`): `pageNumberMarginBoxCss()` мапить позицію на CSS Paged Media margin-box (`@bottom-center`, `@bottom-left`, `@bottom-right`, `@top-left`, `@top-right`, `@top-center`).
- Сумісність: старі значення `'bottom-outside'`/`'top-outside'` автоматично трактуються як `bottom-right`/`top-right` (і в UI, і в експорті); дефолти в `initialBook.ts` і `kdpHelpers.ts` оновлено на `bottom-right`.

**Перевірка:** смоук-тест експорту — усі 6 позицій дають правильний margin-box у обох темах (classic + editorial), legacy-значення мапляться коректно. Перевірка в браузері: 6 кнопок позицій, перемикання «Вгорі, справа» переміщує номер зверху справа.
