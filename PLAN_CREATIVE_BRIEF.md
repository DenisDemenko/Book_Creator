# Т7.2 — бриф і доступ

Приватний бриф і перелік матеріалів зберігаються у Studio поруч з CreativeProject.
Marketplace отримує лише явно підтверджений публічний бриф через API-міст;
модерація/каталог і заявки на creative order — Т7.3. Не надсилати рукопис,
ідентифікатори приватних сутностей чи scope через міст.

1. Конструктор §2.3 з CAS, AI draft тільки за явним запитом, без запису книги.
2. Публічний snapshot після preview/підтвердження автора; нова правка не
   переписує snapshot. До готовності біржі — MODERATION, не OPEN.
3. Дерево книги й конкретних сутностей; NONE за замовчуванням. Зберігати
   вибраний scope для майбутнього виконавця; без автоматичних grants.
4. Для вже активного учасника — конкретний grant Т6.2, строк, відкликання,
   аудит. WORK означає роботу в Creative Studio; текст доступний для
   контексту, а не автоматичного редагування рукопису.
5. Додати object/media_asset/visual_bible до існуючих AccessGrant, фільтрувати
   API, файли, realtime book view. Частини і Style Bible, яких у книзі нема,
   показувати відсутніми, без удаваної реалізації Т7.5.
6. Перевірити Memory/Postgres, CAS, AI failure/stale, publish підтвердження,
   приватність, media download, revocation/expiry, браузер 390 px, тести/збірки.
